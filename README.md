# gradledger

A tool to help graduate-school applicants abroad build a shortlist of universities/programs they can actually defend — not just a confident-sounding list generated by AI.

## The problem

When people use AI (ChatGPT, etc.) to shortlist grad programs, the AI is fluent and encouraging, but the underlying evidence — funding terms, program specifics, admission realities — is scattered, unverified, and often overly optimistic. Applicants end up with a list they can't explain the reasoning behind.

## The approach

- An **evidence ledger**: every claim about a program is tagged with its source and a verified/unverified flag — never invented.
- **Per-claim uncertainty**, not one blended confidence score.
- A required **reason log** every time a program is kept or cut — the AI never auto-decides.
- Compression from a large option set to a small, defensible shortlist through visible trade-offs.

## What this does NOT do

Predict admission chances, hand out a "best school" verdict, or replace official sources.
